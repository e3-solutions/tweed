# Changes after the evaluated instruction bundle froze

The registered enhanced treatment is **candidate 1**, copied before the first
main worker call. Its instructions remain unchanged in every main and follow-up
assignment. The following later production guidance changes are **outside that
comparison**; the comparison cannot establish their efficacy.

- The completed blinded intake review identified two episodes that inferred a
  completion prerequisite from an answer about who owns completion. The question
  guide now distinguishes a necessary condition from a complete decision and
  directs the owner to discover existing behavior before asking an unresolved
  consequential gating choice. This is a response to observed errors, not a
  measured improvement in this trial.
- An independent policy review found an older “native delegation first” sentence
  that conflicted with the new Claude-first default. The harness reference now
  defers to that default and identifies native Codex independent checks or a
  better-qualified route as reasons to use native delegation.
- That review also found that the edit-route checklist specified enforced write
  scope without explicitly specifying enforced authorized source-read scope.
  The checklist now includes source-read enforcement and denied-read probes.

The intake controller's blank-line trailing whitespace was removed after all
twelve episodes had completed. The registered executable is preserved separately
and is also recoverable from the pre-launch Git commit `b662d71`; the cleanup is
cosmetic. Its later retained copy is not represented as a pre-launch snapshot.
Verification must distinguish the registered bytes from the cleaned current file.

Post-run analysis and export tooling is qualified independently with synthetic
counterexamples before it reads real closed results. Corrections to that tooling
do not rewrite the frozen worker controller, primary raw receipts, registered
instructions or assigned roster. An additional current-artifact oracle check,
if needed to resolve a missing historical source binding, is reported separately
from the original recorded verdict.

None of these changes adds an installed dispatcher, dependency, model ladder,
mandatory question count or evidence-report field. The new detailed guidance
loads through conditional references.
