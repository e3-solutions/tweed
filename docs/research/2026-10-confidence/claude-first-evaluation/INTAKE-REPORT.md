# Intake comparison: questions, answers and readiness

All twelve assigned interviews completed with eligible Opus 5.5 receipts. The
same model, medium effort, supplied source facts and scripted-user boundary were
used for baseline and enhanced relevant instructions. Each episode allowed at
most three rounds. [All episode metrics and evidence hashes](intake-results.json)
preserve the outcomes; [the prospective method](PREREGISTRATION.md) defines scope.

| Observation | Baseline, six episodes | Enhanced, six episodes |
| --- | ---: | ---: |
| Eligible episodes | 6 | 6 |
| Decisions covered before the final assistant output | 5 episodes | 5 episodes |
| Final `ready=true` | 1 | 1 |
| Premature readiness detected by the keyword ledger | 0 | 0 |
| Unsupported final readiness identified by blinded semantic review | 1 | 1 |
| Total model rounds | 18 | 17 |
| Questions across all rounds | 84 | 62 |
| Reported CLI list-price estimate, not a bill | $1.0944354 | $1.3878492 |

The question totals describe these transcripts. They do not establish less human
effort or better clarification: the scripted user could answer only a frozen set
of recognized questions. Both policies had one notification episode whose final
readiness inferred an unanswered completion prerequisite. Who owns completion
does not settle whether it waits for children or accepts later child updates.
These are retained counterexamples to the initial universal authority-preservation
claim, rather than positive evidence for either policy.

The enhanced resume episode I02 asked a substantive numeric-precedence question
that the keyword user failed to recognize. The semantic review identifies this
simulator limitation, while the actual unanswered decision remains unresolved.
Eight episodes covered their ledger before the final assistant output but stayed
not-ready. Additional unanswered choices often explain that outcome; the finite
ledger is not a complete model of user intent. Reviewer judgments are limited
evidence, not ground truth, and the analysis makes no aggregate winner claim.

The primary transcript reviewer saw anonymous requirements, source facts, actual
questions, answers and the decision ledger. It received no arm/model labels or
owner conclusions. The mapping was opened only after that review completed.
The subsequent closure analyst is explicitly unblinded. Closure verification
reconstructs all twelve histories and actual provider requests, checks current
stream/receipt bytes and binds the anonymous review to its exact packet.

One retained jury excerpt used a curly apostrophe where the actual transcript
used a straight apostrophe. The first analysis refused it. A later analyzer
correction permits only that typographic normalization, records the non-verbatim
fidelity flag and both value hashes, and still rejects changed words, punctuation
or references. The original jury and transcript bytes are unchanged; eighteen
synthetic tests check this verifier. This parser correction occurred after
outcome access and does not revise the frozen keyword or semantic classifications.

The production question guide now distinguishes necessary conditions from complete
decisions. That correction and the successor measurement contract are
[later revisions](LATER-REVISIONS.md), outside the frozen enhanced treatment.
These interviews implement no code and measure neither autonomous source
discovery, live-user satisfaction nor answer-dependent production behavior.
Observed subscription charges and actual compute remain unknown.
