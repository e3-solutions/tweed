## Six narrow offline control contracts

1. **Admission contention.** Two actual local contender processes use the same real lock path and instrument owned-child intervals. Observed admitted maximum is 1; the second cannot launch its owned child before the first's group cleanup, stream/receipt settlement and source capture. Lock/process errors remain infrastructure gaps; no parent-pause workaround.
2. **Deadline and interruption settlement.** Force timeout of a real owned parent plus SIGTERM-resistant descendant; observe final kill/reap and retained partial stdout/stderr/status. Do not generate a successful terminal. Hold admission until settlement. Record actual containment scope; an unknown live owned descendant or unfinished publication blocks the next call.
3. **Prepare-to-dispatch seal.** Prepare authentic study copies, then independently verify every frozen input and roster before any model. Output creation cannot overwrite a pinned global receipt or enter an input-tree seal. A deliberate synthetic frozen-input mutation must reject dispatch; separately retained generated outputs must not invalidate immutable inputs. No restoration incident may be hidden.
4. **Composed tool confinement.** Exercise actual MCP read/write/execute and executed-child paths: permitted local behavior/baselines run; outside private panel/oracle/control files, forbidden modern recipes and network remain denied. Confidence/capture helpers or nested subprocesses cannot bypass this boundary. Native shell/filesystem/agent tools outside the registered envelope stay absent or denied.
5. **Local target identity.** Owner loading binds supplied module __file__, __spec__.origin, source SHA and tested public callable origins, allowing valid local helpers. Deliberate installed-stdlib substitution/re-export with forged __file__ must fail qualification. Deny the target host .py and matching .pyc prospectively; pin interpreter/native _csv support. Actor checks show actual module identity, not an unbound import that silently uses installed fixed code.
6. **Independent critic and realistic tests.** Genuine base fails the new required behavior; scoped accepted reference passes positives, meaningful negatives and relevant consistent regressions. Causal wrong-fix controls fail. Ordinary product-test edits/additions are allowed and reviewed, not scope failures merely for changing old bytes or normal locations. Frozen owner modules remain untouched and are projected independently of actor test edits; obsolete product assertions are not mandated regressions.

These are controlled CPU fixtures, not fake provider results or a broad test suite. Actual model/session/tool/lifecycle qualification still comes from real call receipts.
