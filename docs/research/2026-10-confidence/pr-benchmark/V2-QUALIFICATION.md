# Qualification for a separate V2 mixed-provider replay

This is a prospective infrastructure qualification record, dated 2026-10-12.
It does not establish that either model or the Confidence Protocol is more
accurate or efficient. The first mixed-provider registration remains intact:
its interrupted, unstarted and unsupported-tool attempts belong in its full
48-assignment denominator. A new adapter and fresh registration define a new
exploratory experiment. Do not resume the original cohort after changing its
adapter or discard invalid attempts from its assigned denominator.

The first controller passed relative stage-control paths to the unchanged
Claude adapter. That adapter launches its MCP server from the actor workspace,
so a coordinator-relative `server-config.json` argument resolves under the wrong
directory. Codex's adapter explicitly resolves those paths. A successful
standalone absolute-path Codex-to-Claude callback control therefore did not
qualify the full relative-path staged pipeline. The failure mechanism is a
transport/path-layout defect, not evidence about model task-solving ability.

`v2_controls.py` owns the full hosted pipeline qualification. It calls the
unchanged `run_trial` through `qualified_invoke`, uses the exact frozen CP0.6
package and the common role/workflow prompts, and records two cross pairings.
Only the task is a clearly identified toy. The verifier rejects missing actual
reads/tests, unavailable effective inventory, wrong final behavior, failed
confidence capture, missing terminals or incomplete required peers/repair, model mismatch, peer source changes
and deadline violations. It does not retry a failing toy or make historical PR
calls. Its nine synthetic verifier controls exercise those rejection cases and
permit a truthful implementation-stage declaration of the scheduled future
adversarial-review gap.

## Fairness and interpretation

V2 must retain all four provider pairings, two repeats and all six tasks; retain
the same role prompts, 90/240/90/120-second stages, 600-second aggregate window,
CP0.6 package revision and independent graders. Only the explicit absolute-path
and transport qualification adaptation changes. Qualification overhead counts
against the aggregate clock; do not describe it as a free compute allowance.
No stage can use an unsupported native capability or fall back to a different
model silently. Record unavailable telemetry as unknown and fail closed on a
missing tool envelope instead of pretending the attempted solution was tested.

Wall windows are common. Tokenization, vendor system prompts, caching, Claude
budget guards, subscription accounting and resource-handler declarations are
different. Codex dollar cost remains null when the CLI does not report it;
reported known subtotals and pinned-rate estimates are separate. Combining
providers can use their separate available accounts, but does not merge or
increase either account's entitlement. Actual software accuracy must be measured
against same-main-model controls, not inferred from model diversity or agreement.

Process-group cleanup does not contain a descendant that creates a new session.
Successful local and hosted toys establish the exercised boundary only. Do not
claim complete descendant containment, absolute artifact immutability, strict
seven-tool parity, whole-PR replication for bounded PR35/PR39 slices, general
population effects from six selected tasks, or cost-matched comparison.
